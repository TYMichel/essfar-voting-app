## essfar-voting-app
Une application Streamlit pour aider les étudiants de l'ESSFAR à élire le président de l'association AGES

### fonctionnement 

Pour ajouter un candidats, il faut : 
1. Ajouter les noms et prenom du candidats dans le fichiers excel `candidats.xlsx`
2. Ajouter l'image du candidat (pas nécéssairement sa photo) dans le dossier `images/candidats`. L'image
doit **obligatoirement**  porter le nom du candidats
